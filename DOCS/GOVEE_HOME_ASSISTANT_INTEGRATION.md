# Govee Smart LED Home Assistant Integration Guide

Leitfaden zur Einbindung von Govee Smart LEDs in Home Assistant (Task #706).

---

## 🔑 1. API Key Beschaffung
1. Öffnen der **Govee Home App** auf dem Smartphone.
2. Navigieren zu `Profil → Einstellungen → Govee API Key anfragen`.
3. Der API-Schlüssel wird per E-Mail zugesendet.

## 🤖 2. Home Assistant Einbindung (VM210 10.1.0.40)
1. In Home Assistant unter `Einstellungen → Geräte & Dienste → Integration hinzufügen`.
2. **Govee** auswählen & den erhaltenen API Key eingeben.
3. Automatische Erkennung aller Govee Light Strips & Lampen.
