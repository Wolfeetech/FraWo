# OpenClaw Quick Slash-Commands Reference

Schnellbefehle für den OpenClaw Telegram-Bot `@Frawo_bot` (Task #164).

---

## ⚡ Verfeinerte Befehle (Telegram Chat)

| Befehl | Aktion | Beispiel |
|---|---|---|
| `/status` | Zeigt den aktuellen System- & Container-Status | `/status` |
| `/radio` | Zeigt den aktuell laufenden Song & Hörerzahl | `/radio` |
| `/anker` | Zeigt offene Getränke-Posten im Anker Tracker | `/anker` |
| `/task` | Erstellt oder sucht eine Aufgabe in Odoo | `/task USV Prüfen` |
| `/help` | Zeigt alle verfügbaren Agenten-Befehle | `/help` |
