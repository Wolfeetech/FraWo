# Warum eine feste Liste:
# In der Bibliothek stehen 600 verschiedene Genre-Angaben für 12.157 Titel.
# Darunter Schreibvarianten desselben Genres ("minimal / deep tech",
# "minimal; deep tech", "Minimal / Deep Tech"), ganze Beatport-Kataloge in
# einem Feld (über 200 Zeichen) und schlicht Werbung ("www.electronicfresh.com").
#
# Damit lässt sich nicht kuratieren. Ein Sender braucht ein Vokabular, das
# man beim Playlistbauen im Kopf hat — erfahrungsgemäss 30 bis 50 Begriffe.
#
# Diese Liste ist aus der tatsächlich vorhandenen Musik abgeleitet, nicht
# erfunden: Jeder Eintrag steht für Material, das wir wirklich haben.
# Alles, was beets sonst finden würde ("seen live", "favourites", Ortsnamen),
# wird verworfen.
#
# Erweitern ist ausdrücklich vorgesehen — aber bewusst, nicht nebenbei.
