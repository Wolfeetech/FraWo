FraWo Funk – Sound-Reactive 3D Demo

1. ZIP-Datei entpacken.
2. index.html im Browser öffnen.
3. „DEMO STARTEN“ anklicken.
4. Mit „INTENSITÄT“ und „REAKTION“ die Wirkung einstellen.

Technik:
- lokaler kurzer Audio-Demoausschnitt
- Web Audio API zur Frequenzanalyse
- Bass steuert räumlichen Puls, Mitten die Farbräume, Höhen die Spektrallinien
- Text, Bedienelemente und Layout werden nicht bewegt
- kein WebGL, keine externe Bibliothek
- reduzierte Bewegung wird berücksichtigt

Status: Nur Demo, keine Änderung an der Live-Seite.
